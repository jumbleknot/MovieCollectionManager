# Files

- [Agent Gateway (LangGraph)](agent-gateway.md) - The Python LangGraph supervisor graph that powers the MCM conversational assistant, served over AG-UI by a FastAPI app, reachable only from the BFF, orchestrating tool calls to three scoped MCP servers through one code-driven chokepoint, owning no domain data, authenticating no end user, and turning any escaping exception into a sanitised terminal RUN_ERROR event rather than an aborted stream.
- [BFF (Backend-for-Frontend)](bff.md)
- [CI/CD pipeline (Forgejo Actions)](ci-cd-pipeline.md) - The three behavior-named Forgejo Actions workflows (guardrails, app-ci, cd-deploy) that gate every PR and drive production deploys — the event-driven trigger-cd handoff, digest-by-git promotion, and why CI runs on every PR regardless of what it touches.
- [MCM Cinema design system](design-system.md) - The Material Design 3 token set and Tamagui 3 component library (@mcm/design-system) shared by the Expo app's web and native builds — its theme-split colour roles, dark default, runtime-only Tamagui wiring, the R1-R7 compliance scan that keeps the app from drifting off it, and the repo-wide Renovate locks that keep its framework versions owned by the Expo SDK.
- [Expo/React Native universal app](expo-app.md) - The universal (web + Android) client for MovieCollectionManager, built on Expo Router (Expo SDK 57), a runtime-only Tamagui 3 and an ESLint 10 flat-config lint setup. Covers the client-side app shape, the settings destination and its area registry, the client network layer that never holds a token, the web security-header layer this process serves, the React Native Testing Library 14 migration that made the render/event API async, and the other client-facing build and test traps.
- [Infrastructure-as-code stacks (local Compose + production Komodo)](infrastructure-stacks.md) - How the four named local Docker Compose stacks (auth, mcm, audit, observability) and the seven production Komodo ResourceSync stacks are defined as config-as-code, the side artifacts that ship with them, and the deploy ordering, interpolation/env_file contract, published-port carve-out and topology rules that keep them from colliding or drifting.
- [Keycloak (Identity and Access Management)](keycloak.md) - The Keycloak IAM instance that fronts the whole MCM platform — realm grumpyrobot and its clients and client roles, the digest-pinned keycloak-service service head, the three realm variants (dev/CI/prod) and why their token lifespans differ, the three separate realm-import paths, RFC 8693 token exchange, the dedicated backup-consent client that keeps grant revocation from ending a member's session, and the realm guards plus service/network topology rules that keep auth reachable.
- [mc-service (Rust/Axum movie-collection service)](mc-service.md) - The Rust/Axum microservice that owns all movie-collection domain logic — CRUD, business-rule validation, and RBAC/DAC enforcement — for MovieCollectionManager, built as four Clean Architecture layers with CQRS, repository, and specification patterns over its own replica-set MongoDB.
- [The three scoped MCP servers](mcp-servers.md) - The three purpose-scoped MCP (Model Context Protocol) servers the Agent Gateway calls as tools — movie-mcp (mc-service proxy carrying the caller's downscoped token), web-api-mcp (outbound TMDB enrichment under the requesting user's own key), and spreadsheet-mcp (token-free file processing over a transient handle) — each with a deliberately narrow identity and network footprint.
- [MovieCollectionManager repository — structure and working conventions](repository.md) - The MCM monorepo itself — its directory layout, polyglot tech stack re-derived from the manifests rather than from the README's moving tech-stack table, the toolchain and lint conventions feature 081 moved (ESLint 10 flat config, the single exact Tamagui 3 pin, pnpm/Nx exact pins), the two supported dev environments (the dev container on a Docker Sandbox microVM as the default, the native host toolchain as the alternative kept for the Android emulator), the four mandatory pre-work gates with a pointer to the other gate classes, and the load-bearing sandbox gotchas, including why egress enforcement lives outside the VM.
- [SAST & SCA static security scanning](sast.md) - Keyless, config-as-code Static Application Security Testing (SAST) and Software Composition Analysis (SCA) across four scanners — Semgrep, cargo-audit, pnpm-audit, and pip-audit — feeding one normalized allowlist-gated CI job (sast) in guardrails.yml.
- [Dev stack env files and local secret generation](stacks.md) - The two-file-per-stack env contract under infrastructure-as-code/docker/stacks — the four committed <stack>.env.example templates that are the single source for each stack's keys and generation kinds, the gitignored <stack>.env files minted from them by scripts/gen-dev-secrets.mjs, how those files become Compose's interpolation source, the fail-fast ${VAR:?…} contract and its documented exceptions, the gen-dev-env.mjs projection with its realm verification, and the traps (back-fill rather than a plain skip, password-on-first-init credentials, the blank template key the generator must never fill).
